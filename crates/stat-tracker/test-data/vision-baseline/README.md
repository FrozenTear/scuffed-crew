# Scuffed Vision baseline fixtures (PR 158)

The single stat cells are name-free crops kept so the digit checks still
have a known glyph. The three full boards are generated by
`report::blank::synth` (flat colours, template digits, no hero icon, no
name, no timer):

- `native_postgame_table_names_blanked.png` is the centred 1664x1007 table.
- `s075_postgame_table_names_blanked.png` is that table resized to 1248x756.
- `s075_tab_board_stats_only.png` is an in-match table at 1248x756.

`committed_baseline_boards_match_the_generator` fails if those files are
replaced with anything else. `tests/integration/vision_baseline_fixtures.rs` reads all
of them.
